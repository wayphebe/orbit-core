# 系统文档：叙事 / 世界观（Narrative）

## 1. 现状叙事载体（As-Is）

当前叙事主要通过“命名 + 短句 + 视觉进化”表达：

- 标题：**ORBIT!**
- 副主题：*A Game About Connection*
- Tier 名称（中/英混合语境里已偏中文）：失联 / 初级 / 中级 / 深度 / 终极
- Tier 描述（英文短句，建议与机制直连）：例如 *Reconnect to restore your abilities*、*10 seconds until you lose your abilities*、*You both can detect and collect*、*Overlap to become a light*

角色的“故事”更多是职责隐喻：

- **Celu**：探测/点亮
- **Ak**：收集/回收

## 2. 主题陈述（可写进宣传文案）

连接不是誓言，而是每一秒的调整。  
你靠近，我就必须学会如何不伤害你；你远去，我就必须决定要不要把你拉回。

## 3. 叙事深化路径（To-Be / TODO）

### 3.1 极简主义（推荐与现状一致）

不讲“剧情”，只讲“关系阶段”：

- 每次 Tier 提升给一句短箴言（可双语）
- 让玩家把自己的协作体验投射成故事

### 3.2 轻文本叙事（中成本）

- 星图日志：每次收集触发一句断片式文本（碎片即记忆）
- 章节标题：用关系动词命名（靠近/对齐/失衡/归航/升华）

### 3.3 结构性叙事（高成本）

- 关卡结构承载关系变化（见 `docs/systems/levels.md`）
- 终局给一个明确的“升华结论”（结算/镜头/音乐高潮）
