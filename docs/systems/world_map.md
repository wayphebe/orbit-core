# 系统文档：世界 / 地图 / 摄像机（World & Map）

## 1. 世界模型（As-Is）

- 2D 连续平面坐标系（像素单位）。
- 没有边界、没有碰撞地形、没有固定的“地图”。
- 世界的“中心”由两角色的**质心**（center of mass）定义。

## 2. 摄像机/视口（As-Is）

- 视口跟随质心：把质心平移到屏幕中心。
- 实现方式：整个“世界容器”做 CSS translate（不是传统 camera 矩阵）。

设计含义：

- 玩家在视觉上始终共享同一个参照系，强化“关系共同体”主题。

## 3. 空间节奏（As-Is）

- 碎片围绕质心生成（环带），因此目标会自然地把玩家“拉回到一起”，避免各自跑远导致游戏散架。

## 4. To-Be / TODO（地图化的可能）

如果要做“地图/关卡”，建议优先考虑仍然围绕“关系中心”展开，而不是做传统固定地图：

- **区域围绕关系出现**：当 Tier 提升时，出现新的“宇宙结构”（障碍/引力井/风暴带）。
- **事件围绕关系触发**：当距离接近阈值时，触发“星潮”改变摩擦、或改变碎片行为。
