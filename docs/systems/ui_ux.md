# 系统文档：UI / UX

## 1. UI 信息架构（As-Is）

### 1.1 主要信息

- **Tier（状态）**：当前羁绊层级名称 + 简短描述
- **Distance（风险）**：两者距离数值（像素）
- **Energy（进度）**：已收集碎片数量（目标 10）

### 1.2 教学与上手

底部常驻键位提示：

- Celu：W/A/S/D
- Ak：↑/←/↓/→

## 2. 视觉语言（As-Is）

- 采用“宇宙面板”样式（半透明、模糊、边框）。
- Tier 颜色贯穿标题、数字与发光效果，形成统一状态反馈。
